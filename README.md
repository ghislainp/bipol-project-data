


This dataset contains measurements of snow specific surface area (SSA) and snow density collected at Dome C, in Antarctica, by Arnaud Mialon and Eric Lefbvre during the "Bipol" project in 2012-2013.


# ./profiles/

Files (csv format) with snow properties profiles.

- z: depth (m)
- density: snow density (kg/m3)
- ssa: specific surface area measured with Asssap on samples (m2/kg)
